# 수요 AI 에이전트 빌더스 강의자료 요약 (채팅 AI 도우미용)

## 모임과 환경
- 학교 선생님들이 AI 에이전트를 직접 다뤄 보는 연수 모임입니다. 대상은 컴퓨터 전문가가 아닌 초·중·고 교사입니다.
- 환경은 Windows와 PowerShell입니다. 에이전트는 네 가지 중 하나를 씁니다: Claude(명령 claude), ChatGPT(Codex CLI, 명령 codex), Gemini(Antigravity CLI, 명령 agy), Grok(Grok Build, 명령 grok). 선생님이 어떤 도구를 쓰는지 모르면 먼저 물어보세요.
- 작업 폴더는 C:\projects 아래에 만듭니다(예: C:\projects\03_python).
- 강의자료는 01 시작하기, 02 에이전트 길들이기, 03 파이썬으로 일하기, 04 MCP로 노션·캔바 연결하기입니다. 05(API 장착), 06(웹앱), 07(배포)는 아직 준비 중입니다.

## 꼭 지킬 원칙 (강의자료의 약속)
- 연습 자료는 모두 가짜입니다. 실제 학생 이름, 연락처, 성적, 상담 내용은 에이전트나 이 채팅에 넣지 않습니다. 파일 내용은 AI 회사 서버로 전송됩니다.
- 에이전트에게 시키기 전에 원본을 백업합니다. 규칙 파일(AGENTS.md)에 "현재 프로젝트 폴더 밖의 파일은 읽거나 쓰지 않는다"를 적어 두고 시작합니다.
- 처음 보는 라이브러리·프로그램은 설치하기 전에 "이거 믿을 만한 거야?"라고 확인합니다. 이름이 비슷한 가짜가 있습니다(예: 한글 파일용은 python-hwpx이고 hwpx가 아닙니다).
- 에이전트가 설치나 삭제처럼 중요한 일을 하려 하면 경로와 내용을 한 줄 읽고 허락합니다.

## 답하는 방법
- 아래 차시별 내용에 있는 명령과 프롬프트를 그대로 알려 주고, 어느 차시 몇 단계인지(예: "03 자료 3-3")를 함께 말해 주세요.
- 자료에 없는 명령이나 메뉴는 지어내지 마세요. 모르면 모른다고 하고 해당 강의자료 페이지를 다시 보라고 안내하세요.
- 선생님이 막혔으면 "무슨 화면이 보이는지, 오류 문구가 무엇인지"를 먼저 물어보세요.
- 선생님이 하고 싶은 일(목적)을 먼저 듣고, 그 일에 맞는 도구나 방법을 에이전트와 함께 찾아보도록 권해 주세요.

### PowerShell 열기
    오늘 설치할 것은 AI 에이전트 하나뿐입니다. 그 전에 명령을 붙여 넣을 창부터 열어 둘게요.
    ※ PS C:\WINDOWS\system32> 가 보인다면
    ※ 관리자 권한으로 연 창입니다. 창 제목에 "관리자"가 붙어 있을 거예요. ⊞ Win + X 메뉴에서 "터미널(관리자)" 바로 위의 "터미널"을 눌러 다시 여세요. 정상이면 PS C:\Users\선생님이름>으로 시작합니다.
    ※ system32는 Windows 핵심 파일이 있는 폴더라, 여기서 에이전트를 실행하면 중요한 파일을 건드릴 수 있습니다. 어느 창이든 에이전트를 부르기 전에는 항상 cd C:\projects로 이동하세요.
    ※ 복사한 명령은 PowerShell 창에서 마우스 오른쪽 클릭 또는 Ctrl + V로 붙여 넣고 Enter를 누릅니다.

### 작업 폴더 만들고 이동하기
    에이전트는 지금 PowerShell이 들어가 있는 폴더 안에서 일합니다. 그래서 일을 시키기 전에는 항상 작업 폴더로 이동부터 합니다. 오늘부터 8주 동안 쓸 작업 폴더를 하나 만들어 둘게요.
- 3-1 C 드라이브에 projects 폴더 만들기
    왼쪽에서 내 PC를 누르고 로컬 디스크 (C:)를 더블클릭합니다.
    ※ 폴더 이름은 영어 소문자, 띄어쓰기 없이 만드세요. 한글이나 띄어쓰기가 들어간 폴더는 명령어에서 오류가 나기 쉽습니다.
- 3-2 PowerShell에서 폴더 이동하기 (cd)
    cd는 "change directory", 즉 폴더로 들어가기입니다. 지금 어디에 있는지는 PS 뒤에 보이는 주소로 알 수 있어요. 아래 순서대로 하나씩 따라 해 보세요.
    · 입력: cd C:\projects
    · 입력: cd ..
    · 입력: cd projects
    · 입력: explorer .
    ※ 처음 주소가 C:\Users\선생님이름이든 C:\WINDOWS\system32든 상관없이, ① cd C:\projects 한 줄이면 어디서든 projects 폴더로 바로 갑니다.
    ※ 꿀팁: cd pro까지만 치고 Tab을 누르면 폴더 이름이 자동으로 완성됩니다.
- 3-3 참고: 명령으로 폴더 만들기
    폴더는 앞으로도 탐색기에서 마우스로 만듭니다. 참고로 PowerShell에서 mkdir 폴더이름 한 줄을 쳐도 지금 위치에 새 폴더가 생깁니다. 지금은 외우지 않아도 됩니다.

### Hello Agent: 첫 지시 4개

- 5-0 연습용 폴더 01_tutorial 만들기
    4단계에서 켠 에이전트는 먼저 끝냅니다. /exit를 입력하거나 Ctrl + C를 두 번 누르세요. PS C:\projects>가 보이면 준비 끝입니다.

    ※ 실습 하나가 끝날 때마다: 에이전트를 끝내고(/exit) → 탐색기에서 01_tutorial 안에 다음 폴더를 만들고 → PowerShell에서 cd로 그 폴더에 들어가 에이전트를 부릅니다. 폴더 이름은 cd로 칠 때 한/영 전환이 필요 없도록 영어로 짓습니다. 명령의 claude 자리는 4단계에서 고른 도구 이름으로 자동으로 바뀝니다.
    ※ "허용하시겠습니까?"라고 물어보면
    ※ 새 폴더에서 처음 부르면 "이 폴더를 믿을 수 있나요?"를 다시 묻습니다. 직접 만든 연습 폴더이니 Yes를 고르세요.
    ※ 에이전트는 파일을 만들거나 명령을 실행하기 전에 확인을 받습니다. 무엇을 하려는지 한 줄 읽어 보고 괜찮으면 허용(Yes)을 고르세요.
    ※ 파일 삭제나 C:\projects 폴더 바깥을 건드리려 하면 거절(No)하고 다시 설명해 주면 됩니다.

- 5-2 학생 10명 폴더 한 번에 만들기

    · 입력: cd C:\projects\01_tutorial\02_students claude

    · 에이전트에게 말하기: 10명의 학생정보.txt를 모두 읽어서 학생명단.csv 표로 모아 주고, 엑셀로 열어줘.
- 5-3 브라우저 띄우기 오늘의 하이라이트
    📁 탐색기에서 01_tutorial 안에 새 폴더 03_welcome를 만든 뒤, PowerShell에서:
    · 입력: cd C:\projects\01_tutorial\03_welcome claude
    · 에이전트에게 말하기: '○○○ 선생님, 환영합니다!'라는 문구가 들어간 환영 카드 웹페이지를 welcome.html로 예쁘게 만들고, 브라우저로 열어줘. 가을 느낌의 색으로 해줘.
    · 에이전트에게 말하기: 글자를 더 크게 하고, 카드에 단풍잎이 천천히 떨어지는 애니메이션을 넣어줘.
- 5-4 미션: 폴더 만들고 웹에서 사진 모아 오기
    📁 탐색기에서 01_tutorial 안에 새 폴더 04_photos를 만든 뒤, PowerShell에서:
    · 입력: cd C:\projects\01_tutorial\04_photos claude
    · 에이전트에게 말하기: '가을 단풍 사진' 폴더를 만들고, 가을 단풍과 관련된 사진 5장을 웹에서 찾아서 그 폴더에 내려받아줘. 파일 이름은 단풍_01.jpg처럼 번호를 붙여줘. 각 사진의 출처 주소와 라이선스는 같은 폴더의 출처.txt에 정리해줘.
    ※ 진행 중에 이런 일이 생길 수 있어요
    ※ "웹 검색을 허용할까요?"처럼 묻는다면 허용하세요. 에이전트가 인터넷에서 찾아보고 내려받는 단계입니다.
    ※ 미리보기가 안 뜨거나 열리지 않는 파일이 있으면, 사진이 아니라 웹페이지를 받아 온 경우입니다. 그대로 말해 주면 스스로 확인하고 다시 받습니다.
    · 에이전트에게 말하기: 단풍_03.jpg가 안 열려. 받은 파일이 진짜 사진인지 하나씩 확인하고, 아닌 건 다른 사진으로 다시 받아줘.
    · 에이전트에게 말하기: 방금 받은 사진들로 5초마다 넘어가는 슬라이드쇼 웹페이지를 만들고 브라우저로 열어줘. 사진 아래에 출처도 작게 넣어줘.
    ※ 오늘은 폴더를 에이전트가 만들었습니다. 탐색기에서 직접 만들던 일을 말 한마디로 맡긴 것입니다. 받은 사진을 수업에 쓰기 전에는 출처.txt를 보고 사용 조건을 확인하세요.
    ※ 에이전트 끝내기: Ctrl + C를 두 번 누르거나 /exit를 입력합니다. 그다음 PowerShell 창을 닫으면 됩니다.

### 막혔을 때
- 질문: 'claude'(또는 codex·agy·grok) 용어가 cmdlet, 함수… 이름으로 인식되지 않습니다
    답: 설치 직후에 자주 나옵니다. PowerShell 창을 닫고 새로 연 뒤 다시 입력하세요. 그래도 안 되면 노트북을 재시작합니다.
- 질문: Codex를 winget으로 설치했는데 'codex'를 못 찾아요
    답: winget용 Codex는 실행 파일 이름이 codex-x86_64-pc-windows-msvc.exe라서, Windows 설정에 따라 'codex'라는 이름이 연결되지 않습니다. 지우고 4-1의 npm 방법으로 다시 설치하세요.
    · 입력: winget uninstall -e --id OpenAI.Codex
- 질문: "이 시스템에서 스크립트를 실행할 수 없으므로…" 오류
    답: 보안 설정 때문입니다. 아래 명령을 먼저 실행한 뒤 설치 명령을 다시 붙여 넣으세요. 지금 연 창에서만 적용되니 안전합니다.
    · 입력: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
- 질문: 'irm'은(는) 내부 또는 외부 명령… 이 아닙니다
    답: PowerShell이 아니라 CMD를 연 것입니다. 창을 닫고 2-1처럼 PowerShell을 다시 여세요. 꼭 CMD를 써야 한다면 Claude Code는 아래 명령으로 설치할 수 있습니다.
    · 입력: curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
- 질문: 설치 명령을 넣었는데 아무 반응이 없어요
    답: winget 명령은 진행 막대가 보여서 멈췄는지 알 수 있습니다. 막대가 몇 분째 그대로면 Ctrl+C로 멈추고 다시 실행하세요.
    답: 보조 방법(irm … | iex)은 진행 표시 없이 내려받습니다. 1~2분 기다려 보고, 새 줄에 PS C:\…>가 다시 나타나면 끝난 것입니다.
- 질문: Codex 공식 설치 스크립트가 "Downloading Codex CLI"에서 멈춰요
    답: Ctrl+C로 멈추고 4-1의 npm 방법(Node.js → 실행 허용 → npm install -g @openai/codex)으로 설치하세요.
- 질문: 'winget' 용어가 … 인식되지 않습니다
    답: Microsoft Store에서 앱 설치 관리자(App Installer)를 설치하거나 업데이트한 뒤 PowerShell을 새로 여세요. 시간이 없으면 설치 탭의 "winget이 없다고 나오거나 설치가 안 될 때"를 펼쳐 보조 방법으로 설치합니다.
- 질문: 나중에 새 버전으로 업데이트하려면?
    답: winget으로 설치한 프로그램은 아래 한 줄로 한꺼번에 업데이트됩니다.
    · 입력: winget upgrade --all
- 질문: 로그인 브라우저 창이 안 떠요

### 울타리 치고 자동 모드 켜기
    "내 컴퓨터를 함부로 뒤지면 어쩌지?"와 "매번 승인 누르기 귀찮다"는 둘 다 맞는 걱정입니다. 그래서 울타리(규칙)를 먼저 치고, 그 안에서는 묻지 않고 일하게(자동 모드) 합니다.

    · 에이전트에게 말하기: 이 폴더에 AGENTS.md 파일을 만들고 어떠한 경우에도 현재 프로젝트 폴더 밖의 파일을 읽거나, 쓰거나, 수정하지 않는다는 규칙을 넣어줘. 하위 폴더는 괜찮아.

### 에이전트와 파이썬

    라이브러리가 아주 많습니다. 파이썬 앱스토어(PyPI)에 올라온 라이브러리 수. 웬만한 일은 누군가 이미 만들어 두었습니다.

    답: 그 파일이 엣지, 엑셀, 한글 등에서 열려 있으면 바꿀 수 없습니다. 열린 창을 닫고 에이전트에게 "다시 해줘"라고 말하세요.

제목: MCP로 노션·캔바 연결하기

### MCP가 뭐예요?
    지금까지 에이전트는 내 컴퓨터의 작업 폴더 안에서만 일했습니다. 노션 페이지나 캔바 디자인은 손댈 수 없었죠. MCP는 에이전트를 다른 서비스에 꽂는 연결 플러그입니다.
    ※ 노션·캔바만 있는 게 아닙니다. 요즘은 많은 서비스가 MCP를 내놓고 있습니다. 오늘 연결하는 방법은 다른 서비스에도 거의 그대로 쓰입니다.

### 준비
    먼저 내가 쓰는 도구를 고르세요. 이 페이지의 명령이 그 도구에 맞게 바뀝니다.
- 1-1 계정 확인
    캔바 계정 (선생님은 캔바 교육용을 무료로 쓸 수 있습니다)
- 1-2 작업 폴더와 실습 파일
    03에서 쓴 가짜 공문 자료를 새 폴더에 받습니다.
    · 입력: mkdir C:\projects\04_mcp -Force; cd C:\projects\04_mcp; Invoke-WebRequest https://kimjkeun.github.io/AI_teachr/assets/samples/tools-sample.zip -OutFile s.zip; Expand-Archive s.zip -DestinationPath . -Force; Remove-Item s.zip; explorer .

### 노션 연결하기
    연결은 두 번에 끝납니다. ① 플러그 꽂기(명령 한 줄) → ② 로그인하고 허용.
- 2-1 플러그 꽂기
    · 입력: claude mcp add --transport http notion https://mcp.notion.com/mcp
    주소 mcp.notion.com은 노션이 직접 운영하는 공식 MCP입니다.
- 2-2 로그인하고 허용
    에이전트를 켜고 /mcp 입력 → notion 고르기 → Authenticate
    · 입력: claude
- 2-3 연결됐는지 확인
    · 에이전트에게 말하기: 노션 연결됐어? 내 노션에 있는 페이지 제목 몇 개만 알려줘.
    내 노션의 페이지 제목이 나오면 성공입니다. 에이전트가 노션 도구를 써도 되는지 물으면 허락하세요.

### 노션에 정리하기
    내 폴더의 파일을 읽고, 결과를 노션에 바로 씁니다. 웹 AI였다면 파일 올리기 → 답 복사 → 노션에 붙여 넣기를 했을 일입니다.
- 3-1 폴더 → 노션
    · 에이전트에게 말하기: 공문 폴더의 PDF 3개를 읽고, 노션에 'AI 연습장' 페이지를 만들어서 할 일과 마감일을 표로 정리해줘.
    확인: 노션을 열어 보세요. 왼쪽 목록에 AI 연습장 페이지가 생기고, 공문 3건의 할 일과 마감일이 표로 들어 있나요?
- 3-2 노션 → 에이전트
    이번에는 거꾸로, 노션에 있는 내용을 읽게 합니다.
    · 에이전트에게 말하기: 노션 'AI 연습장' 페이지를 읽고, 마감이 제일 빠른 일이 뭔지 알려줘.
    ※ 더 해보기: 노션에서 표에 줄 하나를 직접 추가한 뒤 3-2를 다시 물어보세요. 에이전트가 내가 고친 내용까지 읽습니다.

### 캔바 연결하고 만들기
    방법은 노션과 같습니다. 이번에는 스스로 해 보세요.
- 4-1 꽂고, 로그인하기
    에이전트를 /exit로 끄고 PowerShell에서:
    · 입력: claude mcp add --transport http canva https://mcp.canva.com/mcp
- 4-2 폴더 → 캔바
    · 에이전트에게 말하기: 공문 폴더의 체험학습 안내 PDF를 읽고, 캔바에서 학부모님께 보낼 안내 카드를 만들어줘.
    확인: 캔바를 열어 최근 디자인에 새 카드가 있나요? 날짜, 장소, 준비물이 맞게 들어갔는지 내 눈으로 확인합니다.
    · 에이전트에게 말하기: 제목을 더 크게 하고, 준비물은 눈에 띄게 바꿔줘.
- 4-3 노션 + 캔바 함께
    · 에이전트에게 말하기: 노션 'AI 연습장'에 있는 할 일 중 하나를 골라서 캔바로 알림 포스터를 만들어줘.

### 연결 관리와 안전
- 5-1 연결 목록 보기 · 끊기
    · 입력: claude mcp list
    · 입력: claude mcp remove notion
    에이전트 쪽에서 끊어도 서비스 쪽 허용은 남아 있을 수 있습니다. 완전히 끊으려면 노션은 설정 → 연결, 캔바는 설정 → 연결된 앱에서도 해제하세요.
    ※ Claude는 연결을 이 폴더(04_mcp)에만 저장합니다. 다른 폴더에서 켜면 노션·캔바가 연결되어 있지 않습니다.
- 5-2 안전 수칙
    연결하면 서비스 내용도 AI 회사 서버로 갑니다. 에이전트가 읽은 노션 페이지는 내 파일과 마찬가지로 AI에게 전송됩니다.
- 5-3 더 해보기 · 내가 쓰는 서비스는?
    · 에이전트에게 말하기: 구글 캘린더에 연결할 수 있는 MCP가 있어? 공식인지도 알려줘. 아직 연결하지는 마.
    오른쪽 아래 💬 채팅에 "연결해 보고 싶은 서비스"를 한 줄 남겨 주세요.

### 막혔을 때
- 질문: 브라우저 로그인 창이 안 떠요
    답: 터미널에 주소(https://…)가 보이면 그 주소를 복사해 브라우저에 직접 붙여 넣으세요. 로그인과 허용이 끝나면 터미널로 돌아옵니다.
- 질문: 연결했는데 에이전트가 노션을 모른대요
    답: ① 에이전트를 껐다 다시 켜세요. 연결은 켤 때 읽습니다. ② 연결 목록 명령으로 notion이 있는지 보세요. ③ Claude라면 04_mcp 폴더에서 켰는지 확인하세요.
- 질문: 노션 페이지를 못 찾는대요
    답: 로그인할 때 고른 워크스페이스가 맞는지 보세요. 노션 계정이 여러 개면 다른 워크스페이스로 들어갔을 수 있습니다. 연결을 끊고 다시 로그인하면 고칠 수 있습니다.
- 질문: 학교 구글 계정으로 로그인이 막혀요
    답: 학교 계정은 관리자가 외부 앱 연결을 막아 둔 경우가 있습니다. 개인 계정으로 연습하세요.
- 질문: 캔바 디자인이 마음에 안 들어요
    답: 말로 고치면 됩니다. "글씨를 줄여줘", "색을 차분하게 바꿔줘". 마지막 손질은 캔바에서 직접 하는 편이 빠를 때도 많습니다.
