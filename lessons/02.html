1

울타리 치고 자동 모드 켜기

15분

"내 컴퓨터를 함부로 뒤지면 어쩌지?"와 "매번 승인 누르기 귀찮다"는 둘 다 맞는 걱정입니다. 그래서 울타리(규칙)를 먼저 치고, 그 안에서는 묻지 않고 일하게(자동 모드) 합니다.

[내 노트북] 에이전트가 파일을 읽고, 명령을 실행 │ ▲ │ │ "이 명령을 실행해도 될까요?" ▼ │ [AI 회사 서버] 읽은 파일 이름과 내용을 보고 생각
  • 에이전트는 내 노트북에서 일하지만, 생각은 AI 회사 서버에서 합니다. 읽은 내용은 서버로 전송됩니다.
  • 그래서 작업 폴더 안에서만 일하게 하고, 실제 학생 자료(성적, 상담 기록)는 맡기지 않습니다. 오늘 실습 폴더는 전부 가짜 자료입니다.

1-1울타리 규칙 적게 하기

규칙을 내가 직접 쓰지 않고 에이전트에게 받아 적게 합니다. 이번 한 번은 파일을 만드느냐고 물으면 Yes를 고르세요.

에이전트에게
이 폴더에 CLAUDE.md 파일을 만들고 어떠한 경우에도 현재 프로젝트 폴더 밖의 파일을 읽거나, 쓰거나, 수정하지 않는다는 규칙을 넣어줘.

확인: 탐색기에서 02_agent 폴더에 CLAUDE.md가 생겼나요? 메모장으로 열어 직접 고쳐도 됩니다. 존댓말로 답하기 같은 규칙도 나중에 같은 방법으로 더 넣을 수 있습니다.

도구마다 파일 이름이 다릅니다. Claude는 CLAUDE.md, Codex·Antigravity·Grok은 AGENTS.md를 읽습니다. Claude와 Codex에는 /init 명령도 있는데, 이건 에이전트가 폴더를 훑어보고 규칙 초안을 스스로 쓰는 명령입니다. 내 규칙을 넣으려면 위처럼 말로 부탁하는 편이 확실합니다.

1-2다시 켜고 자동 모드로 바꾸기

규칙은 에이전트가 켜질 때 읽습니다. /exit로 끄고 다시 부릅니다.

PowerShell
claude

이제 자동 모드로 바꿉니다: Shift+Tab을 여러 번 눌러 화면 아래에 auto mode가 보이게

Shift+Tab을 누를 때마다 화면 아래 표시가 바뀝니다 (표시 없음) → accept edits → plan mode → auto mode
자동 모드는 "전부 허락"이 아닙니다

평범한 일(파일 읽기, 작업 폴더 안에서 옮기기)은 묻지 않고 진행하고, 위험해 보이는 일은 멈추고 묻습니다. 판단은 AI 검사기가 합니다. 검사기도 틀릴 수 있으니, "모두 허락(bypass, always-approve)" 같은 모드는 쓰지 않습니다.

auto가 안 보이면: 구독 종류나 버전에 따라 아직 없을 수 있습니다. 그때는 수정 자동 허락(accept edits)을 씁니다. 파일 수정은 묻지 않고, 명령 실행은 묻습니다.

1-3울타리가 지켜지는지 시험하기

에이전트에게
내 바탕화면에 있는 파일 목록을 알려줘.
Claude로 미리 해 본 결과 죄송하지만 바탕화면 파일 목록은 확인해 드릴 수 없습니다. 작업 폴더 밖의 파일은 읽지 않는다는 규칙이 있어서…
규칙 파일은 부탁이지 잠금장치가 아닙니다

대부분 잘 지키지만, 대화가 길어지거나 내가 직접 "바탕화면 봐 줘"라고 우기면 놓칠 수 있습니다. 그래서 도구가 주는 진짜 잠금도 함께 알아 둡니다.

  • Claude: 자동 모드에서 폴더 밖을 처음 읽으려 하면 "Read outside the working directories" 창이 뜹니다. No, and block reads outside the working directories from now on을 고르면 이후 모든 폴더에서 폴더 밖 읽기를 막습니다.
  • Codex: /permissions의 Approve for me는 AI 검토자가 나 대신 승인합니다. Full access는 컴퓨터의 어떤 파일이든 묻지 않고 고칠 수 있으니 고르지 않습니다.
  • 어느 도구든: 묻는 창이 뜨면 경로를 한 줄 읽고, 작업 폴더 밖이면 No.
참고: 규칙 파일을 C:\projects에 두면 그 안의 모든 하위 폴더에서 적용됩니다(Claude로 확인). 다른 도구는 확인 중입니다.

엉망 다운로드 폴더 정리

25분

점검 → 계획 → 실행 → 되돌리기 순서로 진행합니다. 실제 업무 파일을 맡길 때도 이 순서를 지키면 안전합니다.

2-1점검만 하기 · 허락과 멈추기

에이전트에게
downloads 폴더를 점검해줘. 파일 개수, 종류별 개수와 용량, 1년 넘게 지난 파일, 이름이나 내용이 같은 중복 파일, 개인정보가 들어 있을 것 같은 파일을 표로 정리해줘. 아무것도 옮기거나 지우지 말고 확인만 해.
자동 모드라서 거의 묻지 않습니다

파일 목록을 읽는 일은 묻지 않고 진행합니다. 그래도 묻는 창이 뜨면 무엇을 하려는지 한 줄 읽고, 경로가 02_agent 안이면 Yes, 밖이면 No를 고릅니다.

멈추기 연습: 에이전트가 일하는 도중에 Esc를 한 번 눌러 보세요. 바로 멈춥니다. "계속해줘"라고 하면 이어서 하고, 다른 지시를 내려도 됩니다. 엉뚱한 방향으로 갈 때 기다리지 말고 멈추는 것이 요령입니다.

이런 것들을 찾아내면 성공 중복 공문 (1).pdf · 학급사진 (1).jpg · 채점기준표 3개 버전 압축 연수자료_모음.zip ← 같은 이름 폴더에 이미 풀려 있음 오래됨 2024년, 2025년 파일들 · 무제.txt · 새 텍스트 문서.txt 개인정보 3학년2반_명렬표.xlsx · 학부모_상담신청_명단.xlsx

2-2파일 짚어 주기 · 화면 보여 주기

어떤 파일을 말하는지 정확히 알려 주는 방법은 두 가지입니다.

  • @ 쓰기: @를 치고 파일 이름 몇 글자를 치면 목록이 뜹니다. 골라서 Enter.
  • 끌어 놓기: 탐색기에서 파일을 PowerShell 창으로 끌어 놓으면 파일 경로가 입력됩니다.
에이전트에게 · 파일은 @나 끌어 놓기로
@downloads/회의록_20250312.txt 이 파일 내용을 두 줄로 요약해줘.

화면 보여 주기: 에러 창이나 화면을 말로 설명하기 어려울 때 캡처해서 보여 줍니다. ⊞ Win + Shift + S로 탐색기 창을 캡처한 뒤 붙여 넣으세요.

  • 붙여 넣기: Alt+V. Ctrl+V로는 이미지가 안 들어가는 경우가 많습니다.
  • 어느 도구든 되는 방법: 캡처는 사진 → 스크린샷 폴더에 자동 저장되니, 그 파일을 PowerShell 창으로 끌어 놓습니다.
캡처를 붙인 뒤
이 화면에서 제일 먼저 정리해야 할 파일 세 개만 골라줘.

2-3계획 모드로 계획부터 받기

계획 모드에서는 에이전트가 파일을 건드리지 않고 계획만 세웁니다. 켜는 법: Shift+Tab을 눌러 화면 아래에 plan mode가 보이게

에이전트에게 · 계획 모드에서
downloads 폴더를 정리할 계획을 세워줘. 문서, 사진, 압축파일로 폴더를 나누고, 중복 파일은 '중복_확인' 폴더로, 개인정보가 든 파일은 '개인정보' 폴더로, 1년 넘은 파일은 '오래된_파일' 폴더로 옮기는 계획이야. 지우는 파일은 하나도 없게 해줘.

계획을 읽고 마음에 안 드는 곳은 말로 고칩니다. 계획이 끝나면 에이전트가 "이대로 진행할까요?"라고 묻습니다. 고칠 게 없으면 진행을 고르세요. 진행한 뒤 화면 아래 표시가 auto가 아니면 1-2처럼 다시 자동 모드로 바꿉니다.

고쳐 말하기 예
채점기준표는 '진짜최종'만 문서 폴더에 두고, 나머지 두 개는 '중복_확인'으로 보내줘. 이제 진행해.

확인: 탐색기에서 downloads 폴더가 깔끔하게 나뉘었나요?

2-4되돌리기

되돌리기 메뉴를 열어 보세요: Esc 두 번 (또는 /rewind). 지금까지 보낸 메시지 목록이 나오고, 고른 시점으로 대화를 돌려 다른 지시를 내릴 수 있습니다. 둘러보기만 하고 Esc로 닫습니다.

대화를 되돌려도 파일은 그대로일 수 있어요

PowerShell 명령으로 옮긴 파일은 되돌리기 메뉴로 돌아오지 않는 경우가 많고, 도구마다 다릅니다. 파일을 확실히 되돌리는 방법은 말로 시키기입니다.

에이전트에게
방금 옮긴 파일을 전부 원래 자리로 되돌려줘. 비게 되는 폴더는 정리해줘.

확인: 탐색기에서 파일이 원래 자리로 돌아왔나요?

그래도 꼬였다면: 탐색기에서 downloads 폴더를 지우고 0-2의 명령을 다시 실행하면 처음 상태로 돌아옵니다. 실제 업무에서는 이 역할을 원본 백업이 합니다.

2-5더 해보기 · 모델과 생각 수준 바꾸기

  • /model: 모델을 바꿉니다. 빠르고 가벼운 모델, 느리지만 똑똑한 모델 중에 고릅니다.
  • /effort: 생각을 얼마나 깊게 할지 정합니다. 간단한 일은 낮게, 까다로운 일은 높게.

바꾼 뒤 2-1의 점검 질문을 다시 해 보고 답의 속도와 꼼꼼함을 비교해 보세요. 높은 모델과 높은 생각 수준은 사용량을 더 많이 씁니다.

3-2새 대화로 시작하기

같은 질문 "우리 방금 무슨 작업 했었지?"를 다시 해 보세요. 이번에는 모릅니다. 그런데 규칙은 그대로 지킵니다. 규칙은 대화가 아니라 파일에 있기 때문입니다.

언제 새 대화를? 주제가 바뀔 때입니다. 대화가 길어지면 에이전트가 앞의 내용과 헷갈리기 쉽고, 매번 긴 대화를 다시 읽느라 사용량도 많이 듭니다.

규칙을 적었는데 안 지켜요

① 에이전트를 껐다 다시 켰는지 확인하세요. 규칙은 켤 때 읽습니다. ② 파일 이름이 내 도구에 맞는지 보세요(Claude는 CLAUDE.md, 나머지는 AGENTS.md). ③ 그래도 놓칠 수 있습니다. 1-3의 도구 잠금과, 묻는 창에서 경로를 보고 No를 고르는 것이 진짜 안전장치입니다.

Shift+Tab을 눌러도 auto가 안 나와요

구독 종류, 도구 버전, 운영체제에 따라 자동 모드가 아직 없을 수 있습니다. 그때는 수정 자동 허락(accept edits)을 고르세요. 파일 수정은 묻지 않고 명령 실행만 묻습니다. "모두 허락"(bypass, always-approve)은 고르지 않습니다.

자동 모드인데도 자꾸 물어봐요

위험해 보이는 일(지우기, 폴더 밖 접근, 인터넷에서 받아 실행하기)은 자동 모드에서도 묻습니다. 정상입니다.

/ 명령을 쳤는데 그냥 메시지로 보내져요

/가 맨 앞에 와야 합니다. 앞에 빈칸이나 다른 글자가 있으면 일반 메시지가 됩니다. /를 치면 뜨는 목록에서 골라도 됩니다.

Alt+V로 캡처가 안 붙어요

캡처 파일을 끌어 놓는 방법을 쓰세요. ⊞ Win + Shift + S로 찍은 캡처는 사진 → 스크린샷 폴더에 저장됩니다. 그 파일을 PowerShell 창으로 끌어 놓으면 됩니다.

Esc를 눌러도 안 멈춰요

한 번 더 눌러 보세요. 그래도 안 되면 Ctrl + C를 한 번만 누릅니다. 두 번 누르면 에이전트가 꺼지는데, 그때는 3-1의 이어 하기로 다시 열면 됩니다.

이어 하기를 했는데 엉뚱한 대화가 열려요 / 아무것도 없대요

이어 하기는 지금 폴더의 마지막 대화를 엽니다. PowerShell의 PS C:\…>가 C:\projects\02_agent인지 확인하세요. 아니면 cd C:\projects\02_agent로 이동한 뒤 다시 합니다.

실습 폴더가 엉망이 됐어요

가짜 자료라 괜찮습니다. 에이전트를 끄고, 탐색기에서 downloads 폴더를 지운 뒤 0-2의 명령을 다시 실행하면 처음 상태가 됩니다.

압축을 풀었더니 파일 이름이 깨져 보여요

탐색기의 "압축 풀기"로 풀면 생길 수 있습니다. 0-2의 PowerShell 명령으로 다시 받아 주세요.
