MCP가 뭐예요?

10분

지금까지 에이전트는 내 컴퓨터의 작업 폴더 안에서만 일했습니다. 노션 페이지나 캔바 디자인은 손댈 수 없었죠. MCP는 에이전트를 다른 서비스에 꽂는 연결 플러그입니다.

[내 작업 폴더] ← 에이전트 → MCP → [노션] MCP → [캔바]
  • USB처럼 규격이 정해져 있습니다. 서비스 회사가 MCP를 만들어 두면, Claude든 Codex든 같은 방법으로 꽂아 쓸 수 있습니다.
  • 연결 = 내 계정을 빌려주는 것입니다. 처음 연결할 때 서비스에 로그인하고 "허용"을 누르면, 에이전트가 내 이름으로 페이지를 읽고 만듭니다.
  • 웹 AI와 다른 점: 내 폴더의 파일과 바깥 서비스를 한 번에 다룹니다. "이 폴더 공문을 읽고 노션에 정리해줘"가 한 문장으로 됩니다.
노션·캔바만 있는 게 아닙니다. 요즘은 많은 서비스가 MCP를 내놓고 있습니다. 오늘 연결하는 방법은 다른 서비스에도 거의 그대로 쓰입니다.
1

준비

5분

먼저 내가 쓰는 도구를 고르세요. 이 페이지의 명령이 그 도구에 맞게 바뀝니다.

1-1계정 확인

  • 노션 계정 (무료 계정이면 충분합니다)
  • 캔바 계정 (선생님은 캔바 교육용을 무료로 쓸 수 있습니다)
  • 학교 업무용 워크스페이스보다 개인 연습용 계정을 권합니다. 이유는 5단계에서 이야기합니다.

1-2작업 폴더와 실습 파일

03에서 쓴 가짜 공문 자료를 새 폴더에 받습니다.

PowerShell
mkdir C:\projects\04_mcp -Force; cd C:\projects\04_mcp; Invoke-WebRequest https://kimjkeun.github.io/AI_teachr/assets/samples/tools-sample.zip -OutFile s.zip; Expand-Archive s.zip -DestinationPath . -Force; Remove-Item s.zip; explorer .

PS C:\projects\04_mcp>가 보이는 상태로 2단계로 갑니다. 에이전트는 아직 켜지 않습니다.

2

노션 연결하기

10분

연결은 두 번에 끝납니다. ① 플러그 꽂기(명령 한 줄) → ② 로그인하고 허용.

2-1플러그 꽂기

PowerShell
claude mcp add --transport http notion https://mcp.notion.com/mcp

주소 mcp.notion.com은 노션이 직접 운영하는 공식 MCP입니다.

2-2로그인하고 허용

에이전트를 켜고 /mcp 입력 → notion 고르기 → Authenticate

PowerShell
claude

브라우저에 노션 화면이 뜨면 로그인하고, 어떤 권한을 주는지 읽은 뒤 허용을 누릅니다. 창을 닫고 터미널로 돌아옵니다.

2-3연결됐는지 확인

에이전트에게
노션 연결됐어? 내 노션에 있는 페이지 제목 몇 개만 알려줘.

내 노션의 페이지 제목이 나오면 성공입니다. 에이전트가 노션 도구를 써도 되는지 물으면 허락하세요.

3

노션에 정리하기

12분

내 폴더의 파일을 읽고, 결과를 노션에 바로 씁니다. 웹 AI였다면 파일 올리기 → 답 복사 → 노션에 붙여 넣기를 했을 일입니다.

3-1폴더 → 노션

에이전트에게
공문 폴더의 PDF 3개를 읽고, 노션에 'AI 연습장' 페이지를 만들어서 할 일과 마감일을 표로 정리해줘.

확인: 노션을 열어 보세요. 왼쪽 목록에 AI 연습장 페이지가 생기고, 공문 3건의 할 일과 마감일이 표로 들어 있나요?

3-2노션 → 에이전트

이번에는 거꾸로, 노션에 있는 내용을 읽게 합니다.

에이전트에게
노션 'AI 연습장' 페이지를 읽고, 마감이 제일 빠른 일이 뭔지 알려줘.
더 해보기: 노션에서 표에 줄 하나를 직접 추가한 뒤 3-2를 다시 물어보세요. 에이전트가 내가 고친 내용까지 읽습니다.
4

캔바 연결하고 만들기

15분

방법은 노션과 같습니다. 이번에는 스스로 해 보세요.

4-1꽂고, 로그인하기

에이전트를 /exit로 끄고 PowerShell에서:

PowerShell
claude mcp add --transport http canva https://mcp.canva.com/mcp

로그인: 에이전트를 켜고 /mcp 입력 → canva 고르기 → Authenticate

4-2폴더 → 캔바

에이전트에게
공문 폴더의 체험학습 안내 PDF를 읽고, 캔바에서 학부모님께 보낼 안내 카드를 만들어줘.

확인: 캔바를 열어 최근 디자인에 새 카드가 있나요? 날짜, 장소, 준비물이 맞게 들어갔는지 내 눈으로 확인합니다.

고쳐 말하기 예
제목을 더 크게 하고, 준비물은 눈에 띄게 바꿔줘.

4-3노션 + 캔바 함께

에이전트에게
노션 'AI 연습장'에 있는 할 일 중 하나를 골라서 캔바로 알림 포스터를 만들어줘.

두 서비스를 오가는 일도 한 문장이면 됩니다.

5

연결 관리와 안전

8분

5-1연결 목록 보기 · 끊기

PowerShell · 목록
claude mcp list
PowerShell · 끊기 (예: 노션)
claude mcp remove notion

에이전트 쪽에서 끊어도 서비스 쪽 허용은 남아 있을 수 있습니다. 완전히 끊으려면 노션은 설정 → 연결, 캔바는 설정 → 연결된 앱에서도 해제하세요.

Claude는 연결을 이 폴더(04_mcp)에만 저장합니다. 다른 폴더에서 켜면 노션·캔바가 연결되어 있지 않습니다.

5-2안전 수칙

  • 연결하면 서비스 내용도 AI 회사 서버로 갑니다. 에이전트가 읽은 노션 페이지는 내 파일과 마찬가지로 AI에게 전송됩니다.
  • 학생 개인정보가 있는 워크스페이스는 연결하지 않습니다. 그래서 1단계에서 개인 연습용 계정을 권했습니다.
  • 공식 MCP만 꽂습니다. 주소가 그 회사 이름(notion.com, canva.com)인지 봅니다. 이름 모를 사람이 만든 MCP는 03의 "가짜 부품"과 같은 위험이 있습니다.
  • 지우기·공유는 꼭 내가 확인합니다. 에이전트가 페이지를 지우거나 공유하려고 하면, 자동 모드여도 한 번 더 읽고 허락하세요.

5-3더 해보기 · 내가 쓰는 서비스는?

에이전트에게 · 서비스 이름만 바꿔서
구글 캘린더에 연결할 수 있는 MCP가 있어? 공식인지도 알려줘. 아직 연결하지는 마.

오른쪽 아래 💬 채팅에 "연결해 보고 싶은 서비스"를 한 줄 남겨 주세요.

막혔을 때

언제든
브라우저 로그인 창이 안 떠요

터미널에 주소(https://…)가 보이면 그 주소를 복사해 브라우저에 직접 붙여 넣으세요. 로그인과 허용이 끝나면 터미널로 돌아옵니다.

연결했는데 에이전트가 노션을 모른대요

① 에이전트를 껐다 다시 켜세요. 연결은 켤 때 읽습니다. ② 연결 목록 명령으로 notion이 있는지 보세요. ③ Claude라면 04_mcp 폴더에서 켰는지 확인하세요.

노션 페이지를 못 찾는대요

로그인할 때 고른 워크스페이스가 맞는지 보세요. 노션 계정이 여러 개면 다른 워크스페이스로 들어갔을 수 있습니다. 연결을 끊고 다시 로그인하면 고칠 수 있습니다.

학교 구글 계정으로 로그인이 막혀요

학교 계정은 관리자가 외부 앱 연결을 막아 둔 경우가 있습니다. 개인 계정으로 연습하세요.

캔바 디자인이 마음에 안 들어요

말로 고치면 됩니다. "글씨를 줄여줘", "색을 차분하게 바꿔줘". 마지막 손질은 캔바에서 직접 하는 편이 빠를 때도 많습니다.
