웹 AI로 하면 어떻게 될까?

5분

과제 21개의 파일 이름을 "번호_이름"으로 바꾸는 일을 웹 챗봇에 맡긴다고 해 볼게요.

웹 챗봇

할 수 있는 건 "이름 목록 제안"까지

  1. 파일 21개를 나눠서 업로드 (개수 제한)
  2. "이렇게 바꾸세요" 목록을 받음
  3. 파일 이름은 내가 하나씩 직접 바꿈
  4. PDF 합치기는 별도 프로그램이나 사이트 필요

CLI 에이전트

폴더를 맡기면 끝

  1. 폴더 안 파일을 직접 열어서 누구 과제인지 확인
  2. 이름을 실제로 바꾸고, 미제출자 엑셀까지 생성
  3. PDF 합치기·나누기도 직접 실행해서 파일로 저장
1

파이썬 준비

10분

엑셀과 PDF를 다루려면 파이썬이 있어야 합니다. 선생님이 파이썬을 배울 필요는 없어요. 설치만 해 두면 에이전트가 필요한 코드를 직접 쓰고 실행합니다.

1-1이미 설치되어 있는지 확인

PowerShell
python --version
Python 3.12.10 ← 버전이 나오면 1-2를 건너뛰세요 Microsoft Store가 열리거나 아무것도 안 나옴 ← 1-2로 설치

1-2설치하기

PowerShell
winget install -e --id Python.Python.3.12

설치가 끝나면 PowerShell 창을 닫고 새로 연 뒤 1-1을 다시 해 보세요.

에이전트에게 맡겨도 됩니다. 에이전트를 켜고 "파이썬이 설치되어 있는지 확인하고, 없으면 설치해줘"라고 말하면 설치 명령을 실행하기 전에 허용을 물어봅니다.

1-3PDF·엑셀 부품은?

PDF는 pypdf, 엑셀은 openpyxl이라는 파이썬 부품(라이브러리)을 씁니다. 따로 설치하지 않아도 에이전트가 필요할 때 "pip install pypdf를 실행할까요?"라고 물어봅니다. 허용하면 됩니다.

실습 파일 받기

5분

가명으로 만든 3학년 2반 실습 파일입니다. 아래 한 줄이 C:\projects\homework 폴더에 내려받아 압축까지 풀어 줍니다.

PowerShell
cd C:\projects; Invoke-WebRequest https://kimjkeun.github.io/AI_teachr/assets/samples/homework-sample.zip -OutFile homework.zip; Expand-Archive homework.zip -DestinationPath . -Force; Remove-Item homework.zip; cd homework; explorer .
C:\projects\homework ├─ 명렬표.xlsx 3학년 2반 25명 (가명) ├─ 과제_제출\ 제출된 과제 21개. 이름이 제각각 │ ├─ 김민지 과제.pdf │ ├─ 03김서준_수행평가.pdf │ ├─ KakaoTalk_20261103_154210.pdf ← 누구 것일까요? │ ├─ 이도현_최종.pdf · 이도현_최종2.pdf │ ├─ 윤서아 과제 사진.jpg │ └─ … ├─ 스캔_학습지_묶음.pdf 복합기로 10명 학습지를 한꺼번에 스캔 └─ 읽어주세요.txt

탐색기 창은 옆에 띄워 두고, PS C:\projects\homework>가 보이면 에이전트를 부릅니다 (claude, codex, agy, grok).

3

실습 1 · 과제 파일 이름 정리

15분
시작 전에: 원본부터 지키기

에이전트는 진짜 파일을 진짜로 바꿉니다. 실제 업무에서도 항상 복사본을 먼저 만들게 하는 습관을 들이세요.

에이전트에게 ①
과제_제출 폴더를 통째로 복사해서 '과제_제출_원본' 폴더로 백업해줘.

3-1계획부터 보기

바로 바꾸지 말고 바뀔 이름 목록을 먼저 받아 봅니다. Claude Code라면 Shift + Tab으로 계획 모드를 켜도 되고, 아래처럼 말로 해도 됩니다.

에이전트에게 ②
명렬표.xlsx를 보고, 과제_제출 폴더의 파일 이름을 '번호_이름.pdf' 형식으로 바꾸려고 해. 번호는 01처럼 두 자리로.
바로 바꾸지 말고, 지금 이름 → 바뀔 이름을 표로 먼저 보여줘.
파일 이름만으로 누구 과제인지 모르겠으면 파일을 열어서 이름을 확인해줘.

지켜볼 점: KakaoTalk_….pdf, 스캔_0001.pdf는 이름이 없죠. 에이전트가 파일을 직접 열어 누구 과제인지 찾아냅니다. 사진(jpg)도 읽습니다.

3-2애매한 것 정해 주기

표를 보면 에이전트가 물어볼 거예요. "이도현은 파일이 2개인데요?" 이럴 땐 정해 주면 됩니다.

에이전트에게 ③
이도현은 최종2가 마지막 제출이니까 그걸 쓰고, 최종은 '14_이도현_이전제출.pdf'로 남겨줘.
윤서아 사진은 PDF로 바꿔서 같은 형식으로 저장해줘. 이제 진행해.

3-3미제출자 명단

에이전트에게 ④
명렬표와 비교해서 미제출자 명단을 '미제출자.xlsx'로 만들어줘. 번호, 이름 열로.

확인: 탐색기에서 미제출자.xlsx를 열어 보세요. 4명이 나오면 정답입니다.

4

실습 2 · PDF 합치기

8분

채점하거나 출력할 때 한 파일로 모아 두면 편합니다. 학생마다 책갈피를 달아 두면 원하는 학생으로 바로 이동할 수 있어요.

에이전트에게
정리한 과제를 번호순으로 하나의 PDF로 합쳐서 '3학년2반_수행평가_모음.pdf'로 저장해줘.
학생마다 책갈피를 '01 강도윤'처럼 달아주고, 이전제출 파일은 빼줘.

확인: 합친 PDF를 크롬이나 엣지로 열고 왼쪽 목차(책갈피)를 눌러 보세요. 학생 이름을 누르면 그 쪽으로 이동합니다.

5

실습 3 · PDF 나누기

12분

스캔_학습지_묶음.pdf는 1~10번 학습지를 복합기에 한꺼번에 넣고 스캔한 파일입니다. 20쪽짜리 한 파일을 학생별로 나눠 보겠습니다.

함정이 있습니다

학생마다 쪽수가 다릅니다. 3번은 추가 답안지까지 3쪽, 6번은 1쪽만 냈어요. "2쪽씩 자르기"로는 엉망이 됩니다. 에이전트가 각 쪽에 적힌 이름을 읽어서 나누게 해 보세요.

에이전트에게
스캔_학습지_묶음.pdf는 10명의 학습지를 한꺼번에 스캔한 파일이야. 학생마다 쪽수가 다를 수 있어.
각 쪽에 적힌 번호와 이름을 읽어서 학생별 PDF로 나누고, '학습지_나눔' 폴더에 '번호_이름.pdf'로 저장해줘.
끝나면 학생별 쪽수를 표로 보여줘.
결과 확인 03_김서준.pdf 3쪽 ← 추가 답안지까지 함께 06_박지호.pdf 1쪽 그 외 8명 2쪽씩
더 해보기: "합친 PDF에서 홀수 쪽만 뽑아줘", "모든 쪽을 오른쪽으로 90도 돌려줘", "5쪽부터 8쪽까지만 따로 저장해줘"
6

보너스 · 더블클릭 도구로 남기기

5분

웹 AI와의 대화는 그때뿐이지만, 에이전트에게는 다음에도 쓸 도구를 만들어 달라고 할 수 있습니다.

에이전트에게
방금 한 PDF 합치기를 다음에도 쓸 수 있게 만들어줘.
바탕화면에 'PDF합치기' 폴더를 만들고, 그 안에 PDF들을 넣은 뒤 'PDF합치기.bat'을 더블클릭하면
파일 이름순으로 합쳐서 '합친파일.pdf'가 생기게 해줘. 사용법도 txt로 같이 넣어줘.

확인: 바탕화면의 PDF합치기 폴더에 아무 PDF나 2개 넣고 PDF합치기.bat을 더블클릭해 보세요. 이제 AI 없이도 언제든 쓸 수 있습니다.

실제 학생 자료로 할 때

꼭 읽기
  • 파일 내용은 AI 회사 서버로 전송됩니다. 에이전트가 파일을 "열어서 확인"하면 그 내용이 AI에게 보내집니다. 학교와 교육청의 개인정보 지침을 먼저 확인하세요.
  • 이름만으로 정리할 수 있는 작업이라면 "파일 내용은 열지 말고 파일 이름만 보고 처리해줘"라고 지시하세요.
  • 성적, 상담 기록처럼 민감한 자료는 맡기지 않습니다.
  • 작업 전에는 언제나 원본 백업을 먼저 합니다.
?

막혔을 때

언제든
python을 입력하면 Microsoft Store가 열려요

Windows에 들어 있는 "가짜 바로가기"입니다. 1-2의 설치 명령으로 파이썬을 설치한 뒤 PowerShell 창을 새로 열면 해결됩니다. 그래도 Store가 열리면 Windows 설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭에서 python.exe, python3.exe를 끕니다.

pip install 중에 오류가 나요

오류 메시지를 그대로 두고 에이전트에게 "방금 오류 고쳐줘"라고 말하세요. 에이전트가 오류를 읽고 다른 방법으로 다시 시도합니다. 학교 와이파이에서 막히면 휴대폰 핫스팟으로 바꿔 보세요.

압축을 풀었더니 파일 이름이 깨져 보여요

탐색기의 "압축 풀기"로 풀면 생길 수 있습니다. 2단계의 PowerShell 명령으로 다시 받아 주세요. 또는 에이전트에게 "homework 폴더 파일 이름이 깨졌어, 고쳐줘"라고 해도 됩니다.

"파일이 사용 중"이라며 이름이 안 바뀌어요

그 PDF가 크롬, 엣지, 한글 등에서 열려 있으면 바꿀 수 없습니다. 열린 창을 닫고 에이전트에게 "다시 해줘"라고 말하세요.

잘못 바꿨어요. 되돌리고 싶어요

처음에 만든 과제_제출_원본 폴더가 있으니 걱정 없습니다. "과제_제출 폴더를 지우고 원본에서 다시 복사해줘"라고 말하면 처음 상태로 돌아갑니다. Claude Code는 입력창이 빈 상태에서 Esc를 두 번 눌러 되돌리기 메뉴를 열 수도 있습니다.
