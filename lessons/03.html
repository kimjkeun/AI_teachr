오늘의 순서

5분

오늘 쓸 도구는 미리 정해 두지 않았습니다. 하고 싶은 일을 말하면 에이전트와 함께 찾아서 고릅니다. 실습마다 아래 순서로 진행합니다.

① 목적 "이걸 하고 싶다" (도구 이름은 몰라도 됨) ↓ ② 도구 찾기 에이전트에게 후보를 찾아 비교해 달라고 하기 ↓ ③ 고르기 기준을 보고 내가 정하기 ↓ ④ 만들기 정한 도구로 에이전트가 설치하고 만들기 ↓ ⑤ 확인 결과를 내 눈으로 보고, 아니면 ②로
  • 도구는 파이썬 부품(라이브러리)일 수도, 설치 프로그램일 수도, 이미 내 컴퓨터에 있는 기능일 수도 있습니다.
  • pip은 파이썬 부품을 내려받는 "부품 가게"입니다. 에이전트가 pip install 이름으로 부품을 받아 씁니다.
1

파이썬 준비

10분

파이썬 부품을 쓰려면 파이썬이 있어야 합니다. 선생님이 파이썬을 배울 필요는 없어요. 설치만 해 두면 에이전트가 코드를 직접 쓰고 실행합니다.

1-1이미 설치되어 있는지 확인

PowerShell
python --version
Python 3.12.10 ← 버전이 나오면 1-2를 건너뛰세요 Microsoft Store가 열리거나 아무것도 안 나옴 ← 1-2로 설치

1-2설치하기

PowerShell
winget install -e --id Python.Python.3.12 --accept-source-agreements --accept-package-agreements

설치가 끝나면 PowerShell 창을 닫고 새로 연 뒤 1-1을 다시 해 보세요.

에이전트에게 맡겨도 됩니다. "파이썬이 설치되어 있는지 확인하고, 없으면 설치해줘"라고 말하면 설치 전에 물어봅니다.

1-3부품은 미리 설치하지 않습니다

PDF용, 엑셀용, 한글용 부품을 미리 깔아 두지 않습니다. 어떤 부품을 쓸지 찾고 고르는 것부터가 오늘의 실습이기 때문입니다.

실습 파일 받기

5분

모두 가짜 자료입니다. 아래 한 줄이 C:\projects\tools 폴더에 내려받아 압축까지 풀어 줍니다.

PowerShell
cd C:\projects; Invoke-WebRequest https://kimjkeun.github.io/AI_teachr/assets/samples/tools-sample.zip -OutFile tools.zip; Expand-Archive tools.zip -DestinationPath . -Force; Remove-Item tools.zip; cd tools; explorer .
C:\projects\tools ├─ 공문\ PDF 3개 (교원연수 · 체험학습 · 안전교육) ├─ 연수교재_전체.pdf 12쪽짜리 교재 ├─ 2학년_명렬표.xlsx 1~3반 36명이 뒤섞인 한 시트 (가명) ├─ 가정통신문_겨울방학.hwpx 한글 문서 ├─ 사진\ 4000×3000 큰 사진 6장 └─ 읽어주세요.txt

탐색기 창은 옆에 띄워 두고, PS C:\projects\tools>가 보이면 에이전트를 부릅니다 (claude, codex, agy, grok).

02에서 배운 것 다시 쓰기: 먼저 "이 폴더에 폴더 밖 금지 규칙 파일을 만들어줘"라고 하고, 다시 켜서 자동 모드로 바꾸세요.
3

함께 해 보기 · 공문 PDF 3개를 하나로

15분

목적은 하나입니다. "공문 폴더의 PDF 3개를 하나로 합치고 싶다." 도구 이름은 몰라도 됩니다.

3-1② 도구 찾기 · 설치하지 말고 후보부터

에이전트에게
공문 폴더의 PDF 3개를 하나로 합치고 싶어. 이 일을 할 수 있는 도구(파이썬 라이브러리나 프로그램) 후보 3개를 찾아서 표로 비교해줘. 무료인지, 최근까지 관리되는지, 인터넷 연결이 필요한지, 설치가 쉬운지. 아직 아무것도 설치하지 말고, 마지막에 어떤 걸 추천하는지 한 줄로 말해줘.
Claude로 미리 해 본 결과 (줄임) pypdf PyMuPDF PDFsam Basic 무료 무료 무료 (배포 시 조건) 무료 (광고 있음) 관리 활발함 활발함 관리 중 인터넷 설치할 때만 설치할 때만 설치 파일 받을 때만 설치 아주 쉬움 쉬움 (파일 큼) 설치 파일 실행 추천: 합치기만 하면 되니 가장 가벼운 pypdf. 코딩 없이 마우스로 하고 싶으면 PDFsam Basic.

도구 이름은 그때그때 달라질 수 있습니다. 중요한 건 후보를 나란히 놓고 비교해 받는 것입니다. 최신 정보로 비교하려고 웹 검색을 해도 되냐고 물으면 허락해도 됩니다.

3-2③ 고르기 · 내가 정한다

표를 보고 내 기준으로 고릅니다. 처음에는 아래 네 가지면 충분합니다.

  • 무료인가: 학교 업무에 써도 되는 조건인가
  • 관리되고 있나: 몇 년째 멈춘 도구는 오류가 나도 고쳐지지 않습니다
  • 내 파일이 밖으로 나가나: "PDF 합치기 사이트"처럼 파일을 올리는 방식은 피합니다
  • 다음에도 쓸 수 있나: 한 번 깔면 계속 쓸 수 있는지
이름이 비슷한 가짜 부품을 조심하세요

부품 가게(PyPI)에는 누구나 올릴 수 있어서, 이름만 비슷한 수상한 부품도 있습니다. 예를 들어 한글 파일용 부품은 python-hwpx인데, 이름이 hwpx뿐인 다른 부품도 있습니다. 설치 전에 "이 부품이 공식 이름이 맞는지, 누가 만들었는지, 최근 업데이트가 언제인지 확인해줘"라고 한 번 더 물어보세요.

3-3④ 만들기 · ⑤ 확인

에이전트에게 · 고른 도구 이름으로 바꿔서
pypdf로 하자. 설치하고, 공문 폴더의 PDF를 파일 이름 순서로 합쳐서 '공문_모음.pdf'로 저장해줘. 공문마다 책갈피도 달아줘.

확인: 공문_모음.pdf를 엣지로 열어 4쪽인지, 왼쪽 목차(책갈피)에 공문 3개가 보이는지 보세요. 마음에 안 들면 ②로 돌아가 다른 도구를 골라도 됩니다. 처음 보는 일이 생겨도 이 순서 그대로 하면 됩니다.

4

혼자 해 보기 · 미션 카드

15분

하나를 골라 같은 순서(목적 → 도구 찾기 → 고르기 → 만들기 → 확인)로 해 보세요. 카드에는 하고 싶은 일만 적혀 있고, 도구는 에이전트와 함께 찾습니다.

A엑셀 · 반별로 나누기

목적: 2학년_명렬표.xlsx에 1~3반이 뒤섞여 있다. 반마다 시트를 따로 만들고, 번호순으로 정렬하고 싶다.

참고 · 에이전트가 흔히 내놓는 후보

openpyxl, pandas, 엑셀 자체 기능(필터·정렬). 원본을 바꿀지, 새 파일로 저장할지도 정해 주세요.

B한글(HWPX) · 내용 뽑기

목적: 가정통신문_겨울방학.hwpx에서 날짜와 할 일만 뽑아 메모장 파일로 정리하고 싶다. 한글 프로그램은 열지 않고.

참고 · 에이전트가 흔히 내놓는 후보

python-hwpx, 한글 프로그램 자동화(pyhwpx, 한글이 설치되어 있어야 함), HWPX가 압축 파일이라는 점을 이용해 직접 열기. 3-2의 가짜 부품 주의를 떠올리세요.

CPDF · 몇 쪽만 떼기

목적: 연수교재_전체.pdf(12쪽)에서 "개인정보 보호" 장만 따로 PDF로 저장하고 싶다. 몇 쪽인지는 모른다.

참고 · 에이전트가 흔히 내놓는 후보

pypdf, PyMuPDF. 쪽 번호를 모르니 "각 쪽 제목을 읽어서 찾아줘"라고 하면 됩니다.

D사진 · 한꺼번에 줄이기

목적: 사진 폴더의 큰 사진 6장을 가정통신문에 넣기 좋게 가로 1200픽셀로 줄여 '사진_작게' 폴더에 저장하고 싶다. 원본은 그대로.

참고 · 에이전트가 흔히 내놓는 후보

Pillow, Windows에 이미 있는 기능(PowerShell), 사진 편집 프로그램. "설치 없이 되는 방법이 있나"도 물어볼 만합니다.

다 했으면 다른 카드도 해 보세요. 두 번째 카드는 훨씬 빠릅니다. 순서가 손에 익기 때문입니다.

내 목적으로 해 보기 & 마무리

10분

이제 카드 대신 선생님의 목적을 넣습니다. 아래 주문서를 복사해 두고, 하고 싶은 일이 생길 때마다 빈칸만 바꿔 쓰세요.

도구 찾기 주문서
하고 싶은 일: (예: 학급 사진 100장에 날짜를 넣고 싶다)
조건: 무료, 내 파일이 인터넷으로 올라가지 않을 것, 다음에도 쓸 수 있을 것
이 일을 할 수 있는 도구 후보 3개를 찾아 표로 비교해줘. 설치는 내가 고른 뒤에 해줘.

5-1소감 남기기

오른쪽 아래 💬 채팅에 "내가 해결하고 싶은 일" 한 줄을 남겨 주세요. 다음 모임에서 함께 도구를 찾아봅니다.

5-2더 해보기 · 다음에도 쓰게 남기기

만든 것을 매번 에이전트에게 부탁하지 않고 쓰고 싶다면, 그것도 목적입니다.

에이전트에게
방금 한 일을 다음에도 쓸 수 있게 이 폴더에 더블클릭하면 실행되는 파일로 만들어줘. 사용법도 txt로 같이 넣어줘.

실제 학생 자료로 할 때

꼭 읽기
  • 파일 내용은 AI 회사 서버로 전송됩니다. 에이전트가 파일을 "열어서 확인"하면 그 내용이 AI에게 보내집니다. 학교와 교육청의 개인정보 지침을 먼저 확인하세요.
  • 이름만으로 정리할 수 있는 작업이라면 "파일 내용은 열지 말고 파일 이름만 보고 처리해줘"라고 지시하세요.
  • 성적, 상담 기록처럼 민감한 자료는 맡기지 않습니다.
  • 도구를 고를 때 파일을 인터넷에 올리는 방식(온라인 변환 사이트 등)은 고르지 않습니다.
  • 작업 전에는 언제나 원본 백업을 먼저 합니다.

막혔을 때

언제든
python을 입력하면 Microsoft Store가 열려요

Windows에 들어 있는 "가짜 바로가기"입니다. 1-2의 설치 명령으로 파이썬을 설치한 뒤 PowerShell 창을 새로 열면 해결됩니다. 그래도 Store가 열리면 Windows 설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭에서 python.exe, python3.exe를 끕니다.

pip install 중에 오류가 나요

오류 메시지를 그대로 두고 에이전트에게 "방금 오류 고쳐줘"라고 말하세요. 에이전트가 오류를 읽고 다른 방법으로 다시 시도합니다. 계속 안 되면 "다른 후보로 해 보자"도 좋은 선택입니다.

후보가 너무 많거나 무슨 말인지 모르겠어요

"선생님이 쓰기에 제일 쉬운 것 하나만 골라서 이유를 쉬운 말로 설명해줘"라고 하세요. 고르는 연습은 두세 번째부터 해도 됩니다.

이 부품이 믿을 만한지 어떻게 알아요?

에이전트에게 "PyPI에서 이 부품의 정확한 이름, 만든 곳, 최근 업데이트 날짜, 많이 쓰이는지 확인해줘"라고 하세요. 이름이 비슷한 부품이 여러 개면 설명과 만든 곳이 분명한 것을 고릅니다.

압축을 풀었더니 파일 이름이 깨져 보여요

탐색기의 "압축 풀기"로 풀면 생길 수 있습니다. 2단계의 PowerShell 명령으로 다시 받아 주세요.

"파일이 사용 중"이라며 저장이 안 돼요

그 파일이 엣지, 엑셀, 한글 등에서 열려 있으면 바꿀 수 없습니다. 열린 창을 닫고 에이전트에게 "다시 해줘"라고 말하세요.
