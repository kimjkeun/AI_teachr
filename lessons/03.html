1-2파이썬은 앱이 없는 스마트폰

새 스마트폰을 사면 전화와 문자 정도만 됩니다. 은행 일을 하려면 은행 앱을, 길을 찾으려면 지도 앱을 깔죠. 파이썬도 똑같습니다. 파이썬만 설치하면 기본 기능뿐이고, 엑셀이나 PDF를 다루려면 그 용도에 맞는 라이브러리를 설치해야 합니다. 라이브러리는 파이썬의 앱입니다.

📱 스마트폰🐍 파이썬
스마트폰 본체=파이썬
앱 (은행, 지도, 카메라…)=라이브러리 (엑셀용, PDF용, 한글용…)
앱스토어 · Play 스토어=PyPI (파이썬 앱스토어)
'설치' 버튼=pip install 라이브러리이름
이름만 비슷한 가짜 앱=이름만 비슷한 가짜 라이브러리

3-1직접 설치해 보기

          
PS C:\projects\03_python>에서 입력합니다. 1-3에서 눌러 본 '설치' 버튼을 진짜로 누르는 것입니다.

스마트폰 홈 화면에서 깔린 앱을 보듯, 설치된 라이브러리 목록을 봅니다.

            이름이 비슷한 가짜 라이브러리를 조심하세요
            
앱스토어에 가짜 앱이 있듯, PyPI에도 누구나 올릴 수 있어서 이름만 비슷한 수상한 라이브러리가 있습니다. 예를 들어 한글 파일용은 python-hwpx인데, 이름이 hwpx뿐인 다른 라이브러리도 있습니다. 처음 보는 라이브러리를 설치하기 전에는 에이전트에게 "이거 믿을 만한 거야?"라고 한 번 물어보세요.

          

        


        

          
3-3에이전트에게 연습용 PDF 만들게 하기

          
02에서 배운 것 다시 쓰기: 에이전트를 부르고(claude, codex, agy, grok) 먼저 "이 폴더에 폴더 밖 금지 규칙 파일을 만들어줘"라고 한 뒤, 다시 켜서 자동 모드로 바꾸세요.

          
에이전트에게
연습용 PDF를 만들어줘. 10쪽이고, 1부 3쪽, 2부 4쪽, 3부 3쪽이야. 쪽마다 '몇 부 몇 쪽'을 크게 적어줘.

          
확인: 폴더에 PDF가 생겼나요? 엣지로 열어 10쪽이고 쪽마다 "1부 1쪽"처럼 적혀 있는지 보세요.

          

            pypdf만으로는 PDF를 새로 만들 수 없습니다
            
pypdf는 있는 PDF를 자르고 붙이는 라이브러리입니다. 새로 만드는 일에는 다른 라이브러리가 필요해서, 에이전트가 직접 하나 골라 설치합니다(예: reportlab). 설치해도 되냐고 물으면 "응, 설치해"라고 답하세요. 한 라이브러리가 못 하는 일은 다른 앱을 깔아서 합니다.

확인: 일부_합본.pdf가 6쪽이고, 1부 3쪽 다음에 3부 3쪽이 이어지는지 보세요. 2부는 빠져 있어야 합니다.

          python을 입력하면 Microsoft Store가 열려요
          
Windows에 들어 있는 "가짜 바로가기"입니다. 2-2의 설치 명령으로 파이썬을 설치한 뒤 PowerShell 창을 새로 열면 해결됩니다. 그래도 Store가 열리면 Windows 설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭에서 python.exe, python3.exe를 끕니다.

        

        

          'pip'을 찾을 수 없다고 나와요
          
앞에 python -m을 붙여 보세요. 예: python -m pip install pypdf. 같은 일을 합니다.

        

        

          pip install 중에 오류가 나요
          
오류 메시지를 그대로 두고 에이전트에게 "방금 오류 고쳐줘"라고 말하세요. 에이전트가 오류를 읽고 다른 방법으로 다시 시도합니다.

        

        

          이 라이브러리가 믿을 만한지 어떻게 알아요?
          
에이전트에게 "이거 믿을 만한 거야?"라고 물어보세요. 공식 이름, 만든 곳, 최근 업데이트를 확인해 줍니다. 이름이 비슷한 라이브러리가 여러 개면 설명과 만든 곳이 분명한 것을 고릅니다.

        

        

          PDF나 그림에서 한글이 네모(□)로 나와요
          
글꼴 문제입니다. 에이전트에게 "한글이 네모로 나와. 맑은 고딕으로 고쳐줘"라고 말하세요.

        

        

          한글 파일이 안 열린다고 해요 (.hwp)
          
python-hwpx는 .hwpx만 엽니다. 한글에서 파일을 열고 파일 → 다른 이름으로 저장 → 파일 형식: HWPX로 저장한 사본을 쓰세요.

        

        

          엑셀의 평균이 비어 있어요
          
에이전트가 엑셀 수식으로만 저장했기 때문입니다. 엑셀에서 열면 계산되어 보이지만, 에이전트가 읽을 때는 값이 비어 있습니다. "값으로 넣어줘"라고 말하세요.

        

        

          "파일이 사용 중"이라며 저장이 안 돼요
          
그 파일이 엣지, 엑셀, 한글 등에서 열려 있으면 바꿀 수 없습니다. 열린 창을 닫고 에이전트에게 "다시 해줘"라고 말하세요.
