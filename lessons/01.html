    PowerShell 열기

    5분

    오늘 설치할 것은 AI 에이전트 하나뿐입니다. 그 전에 명령을 붙여 넣을 창부터 열어 둘게요.

    1. 키보드에서 ⊞ Win + X를 누릅니다.
    2. 터미널 (또는 Windows PowerShell)을 클릭합니다. 관리자 권한은 필요 없습니다.
    3. 창 맨 앞에 PS가 보이는지 확인합니다.
    PS C:\Users\선생님이름> ← 앞에 PS가 보이면 정답 C:\Users\선생님이름> ← PS가 없으면 CMD입니다. 창을 닫고 다시 열어 주세요
    PS C:\WINDOWS\system32> 가 보인다면

    관리자 권한으로 연 창입니다. 창 제목에 "관리자"가 붙어 있을 거예요. ⊞ Win + X 메뉴에서 "터미널(관리자)" 바로 위의 "터미널"을 눌러 다시 여세요. 정상이면 PS C:\Users\선생님이름>으로 시작합니다.

    system32는 Windows 핵심 파일이 있는 폴더라, 여기서 에이전트를 실행하면 중요한 파일을 건드릴 수 있습니다. 어느 창이든 에이전트를 부르기 전에는 항상 cd C:\projects로 이동하세요.

    복사한 명령은 PowerShell 창에서 마우스 오른쪽 클릭 또는 Ctrl + V로 붙여 넣고 Enter를 누릅니다.

    작업 폴더 만들고 이동하기

    5분

    에이전트는 지금 PowerShell이 들어가 있는 폴더 안에서 일합니다. 그래서 일을 시키기 전에는 항상 작업 폴더로 이동부터 합니다. 오늘부터 8주 동안 쓸 작업 폴더를 하나 만들어 둘게요.

    3-1C 드라이브에 projects 폴더 만들기

    1. ⊞ Win + E로 파일 탐색기를 엽니다.
    2. 왼쪽에서 내 PC를 누르고 로컬 디스크 (C:)를 더블클릭합니다.
    3. 빈 곳에서 마우스 오른쪽 클릭 → 새로 만들기 → 폴더.
    4. 이름을 projects로 적고 Enter.
    탐색기 주소창에 이렇게 보이면 성공 내 PC › 로컬 디스크 (C:) › projects
    폴더 이름은 영어 소문자, 띄어쓰기 없이 만드세요. 한글이나 띄어쓰기가 들어간 폴더는 명령어에서 오류가 나기 쉽습니다.

    3-2PowerShell에서 폴더 이동하기 (cd)

    cd는 "change directory", 즉 폴더로 들어가기입니다. 지금 어디에 있는지는 PS 뒤에 보이는 주소로 알 수 있어요. 아래 순서대로 하나씩 따라 해 보세요.

    ① projects 폴더로 바로 가기
    cd C:\projects
    ② 한 단계 위(상위 폴더)로 나가기
    cd ..
    ③ 지금 위치 안의 projects 폴더로 들어가기
    cd projects
    ④ 지금 폴더를 탐색기 창으로 열기
    explorer .

    내 컴퓨터 폴더 지도

    연습용 PowerShell (진짜가 아니라서 마음껏 쳐 봐도 됩니다)

    처음 주소가 C:\Users\선생님이름이든 C:\WINDOWS\system32든 상관없이, ① cd C:\projects 한 줄이면 어디서든 projects 폴더로 바로 갑니다.
    꿀팁: cd pro까지만 치고 Tab을 누르면 폴더 이름이 자동으로 완성됩니다.

    3-3참고: 명령으로 폴더 만들기

    폴더는 앞으로도 탐색기에서 마우스로 만듭니다. 참고로 PowerShell에서 mkdir 폴더이름 한 줄을 쳐도 지금 위치에 새 폴더가 생깁니다. 지금은 외우지 않아도 됩니다.

    Hello Agent: 첫 지시 4개

    30분

    실습마다 새 폴더를 만들고 그 안에서 에이전트를 부릅니다. 작업이 섞이지 않고, 결과물을 나중에 찾기도 쉽습니다. 에이전트에게는 한국어로 말하면 됩니다.

    5-0연습용 폴더 01_tutorial 만들기

    4단계에서 켠 에이전트는 먼저 끝냅니다. /exit를 입력하거나 Ctrl + C를 두 번 누르세요. PS C:\projects>가 보이면 준비 끝입니다.

    1. 열어 둔 탐색기에서 C:\projects 폴더 안의 빈 곳을 마우스 오른쪽 클릭 → 새로 만들기 → 폴더. (단축키 Ctrl + Shift + N)
    2. 이름을 01_tutorial로 적고 Enter.
    참고 · mkdir: PowerShell에서 mkdir 01_tutorial이라고 쳐도 같은 폴더가 만들어집니다. 오늘은 탐색기로 만들고, 명령은 이런 게 있다는 것만 알아 두세요.

    오늘 실습이 끝나면 폴더가 이렇게 쌓입니다.

    C:\projects └─ 01_tutorial ├─ 01_hello ← 5-1 ├─ 02_students ← 5-2 ├─ 03_welcome ← 5-3 └─ 04_photos ← 5-4
    실습 하나가 끝날 때마다: 에이전트를 끝내고(/exit) → 탐색기에서 01_tutorial 안에 다음 폴더를 만들고 → PowerShell에서 cd로 그 폴더에 들어가 에이전트를 부릅니다. 폴더 이름은 cd로 칠 때 한/영 전환이 필요 없도록 영어로 짓습니다. 명령의 claude 자리는 4단계에서 고른 도구 이름으로 자동으로 바뀝니다.
    "허용하시겠습니까?"라고 물어보면

    새 폴더에서 처음 부르면 "이 폴더를 믿을 수 있나요?"를 다시 묻습니다. 직접 만든 연습 폴더이니 Yes를 고르세요.

    에이전트는 파일을 만들거나 명령을 실행하기 전에 확인을 받습니다. 무엇을 하려는지 한 줄 읽어 보고 괜찮으면 허용(Yes)을 고르세요.

    파일 삭제나 C:\projects 폴더 바깥을 건드리려 하면 거절(No)하고 다시 설명해 주면 됩니다.

    5-1파일 만들기

    📁 탐색기에서 01_tutorial 안에 새 폴더 01_hello를 만든 뒤, PowerShell에서:

    PowerShell · 연습 폴더로 이동
    cd C:\projects\01_tutorial\01_hello
claude

    확인: 열어 둔 탐색기 창에서 01_tutorial → 01_hello 폴더를 열어 보세요. 환영합니다.txt가 생겼나요? 더블클릭해서 내용을 열어 보세요.

    5-2학생 10명 폴더 한 번에 만들기

    📁 탐색기에서 01_tutorial 안에 새 폴더 02_students를 만든 뒤, PowerShell에서:

    PowerShell · 연습 폴더로 이동
    cd C:\projects\01_tutorial\02_students
claude
    에이전트에게
    가상의 학생 10명의 폴더를 '01_김민지'처럼 '번호_이름' 형식으로 만들어줘. 이름은 실제 인물이 아닌 가명으로 해 주고, 각 폴더 안에 '학생정보.txt'를 만들어서 번호, 이름, 생일, 좋아하는 과목, 장래 희망을 간단히 적어줘.

    확인: 탐색기에서 02_students를 열면 폴더 10개가 번호순으로 보이나요? 아무 폴더나 열어 학생정보.txt를 확인해 보세요. 웹 챗봇은 폴더를 만들 수 없지만, 에이전트는 10개를 한 번에 만듭니다.

    막혔을 때

    언제든
    'claude'(또는 codex·agy·grok) 용어가 cmdlet, 함수… 이름으로 인식되지 않습니다

    설치 직후에 자주 나옵니다. PowerShell 창을 닫고 새로 연 뒤 다시 입력하세요. 그래도 안 되면 노트북을 재시작합니다.

    Codex를 winget으로 설치했는데 'codex'를 못 찾아요

    winget용 Codex는 실행 파일 이름이 codex-x86_64-pc-windows-msvc.exe라서, Windows 설정에 따라 'codex'라는 이름이 연결되지 않습니다. 지우고 4-1의 npm 방법으로 다시 설치하세요.

    winget uninstall -e --id OpenAI.Codex
    "이 시스템에서 스크립트를 실행할 수 없으므로…" 오류

    보안 설정 때문입니다. 아래 명령을 먼저 실행한 뒤 설치 명령을 다시 붙여 넣으세요. 지금 연 창에서만 적용되니 안전합니다.

    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
    'irm'은(는) 내부 또는 외부 명령… 이 아닙니다

    PowerShell이 아니라 CMD를 연 것입니다. 창을 닫고 2-1처럼 PowerShell을 다시 여세요. 꼭 CMD를 써야 한다면 Claude Code는 아래 명령으로 설치할 수 있습니다.

    curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
    설치 명령을 넣었는데 아무 반응이 없어요

    winget 명령은 진행 막대가 보여서 멈췄는지 알 수 있습니다. 막대가 몇 분째 그대로면 Ctrl+C로 멈추고 다시 실행하세요.

    보조 방법(irm … | iex)은 진행 표시 없이 내려받습니다. 1~2분 기다려 보고, 새 줄에 PS C:\…>가 다시 나타나면 끝난 것입니다.

    Codex 공식 설치 스크립트가 "Downloading Codex CLI"에서 멈춰요

    Ctrl+C로 멈추고 4-1의 npm 방법(Node.js → 실행 허용 → npm install -g @openai/codex)으로 설치하세요.

    'winget' 용어가 … 인식되지 않습니다

    Microsoft Store에서 앱 설치 관리자(App Installer)를 설치하거나 업데이트한 뒤 PowerShell을 새로 여세요. 시간이 없으면 설치 탭의 "winget이 없다고 나오거나 설치가 안 될 때"를 펼쳐 보조 방법으로 설치합니다.

    나중에 새 버전으로 업데이트하려면?

    winget으로 설치한 프로그램은 아래 한 줄로 한꺼번에 업데이트됩니다.

    winget upgrade --all
    로그인 브라우저 창이 안 떠요

    PowerShell 화면에 https://로 시작하는 주소가 보이면, 그 주소를 마우스로 드래그해 복사한 뒤 크롬 주소창에 붙여 넣으세요. 로그인 후 받은 코드가 있으면 PowerShell에 붙여 넣습니다.

    백신(Windows 보안)이 파일을 막았다고 나와요

    Windows 11에서 새 프로그램을 처음 실행할 때 잠시 검사하는 경우가 있습니다. 몇 분 기다린 뒤 다시 실행해 보세요. 계속 막히면 강사에게 알려 주세요.
