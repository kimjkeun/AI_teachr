웹 챗봇 vs CLI 에이전트

10분

같은 일, "공문 폴더 10개를 요약해서 할 일 목록으로 정리하기"를 시킨다고 해 볼게요.

웹 챗봇 (지금까지)

내가 옮겨 주는 AI

  1. 파일을 하나씩 찾아서 업로드
  2. 답변을 복사
  3. 한글·엑셀에 붙여 넣고 정리
  4. 파일이 많으면 나눠서 반복

CLI 에이전트 (오늘부터)

내 폴더에서 직접 일하는 AI

  1. "이 폴더 공문 전부 읽고 할 일 정리해서 파일로 저장해줘"
  2. 끝. 결과 파일이 폴더에 생깁니다

Q.터미널이 뭔가요?

  • 마우스 대신 글자로 컴퓨터에 지시하는 창입니다. 검은 화면에 글자만 있는 그 창이에요.
  • 예전에는 명령어를 외워야 했지만, 이제는 그 안에서 AI 비서를 불러 한국어로 말하면 됩니다.
  • 오늘 외울 명령어는 거의 없습니다. 이 페이지의 복사 버튼만 누르세요.

공통 준비

10분

2-1PowerShell 열기

  1. 키보드에서 ⊞ Win + X를 누릅니다.
  2. 터미널 (또는 Windows PowerShell)을 클릭합니다. 관리자 권한은 필요 없습니다.
  3. 창 맨 앞에 PS가 보이는지 확인합니다.
PS C:\Users\선생님이름> ← 앞에 PS가 보이면 정답 C:\Users\선생님이름> ← PS가 없으면 CMD입니다. 창을 닫고 다시 열어 주세요
복사한 명령은 PowerShell 창에서 마우스 오른쪽 클릭 또는 Ctrl + V로 붙여 넣고 Enter를 누릅니다.

2-2Git for Windows 설치 권장

에이전트가 명령을 더 안정적으로 실행하게 도와주는 프로그램입니다. 아래 명령을 붙여 넣으면 자동으로 설치됩니다.

winget install --id Git.Git -e
winget이 안 되면 git-scm.com/downloads/win에서 내려받아 계속 Next만 누르셔도 됩니다.

2-3VS Code 설치

에이전트가 만든 파일을 열어 보는 메모장 같은 프로그램입니다.

winget install --id Microsoft.VisualStudioCode -e
설치 후 VS Code를 열고 왼쪽 확장(□ 4개 모양) 아이콘에서 Korean Language Pack을 검색해 설치하면 메뉴가 한국어로 바뀝니다.
설치가 끝나면 PowerShell 창을 닫고 새로 여세요

새로 설치한 프로그램은 새 창에서부터 인식됩니다. 오늘 가장 자주 쓰는 해결법입니다.

작업 폴더 만들고 이동하기

5분

에이전트는 지금 PowerShell이 들어가 있는 폴더 안에서 일합니다. 그래서 일을 시키기 전에는 항상 작업 폴더로 이동부터 합니다. 오늘부터 8주 동안 쓸 작업 폴더를 하나 만들어 둘게요.

3-1C 드라이브에 project 폴더 만들기

  1. ⊞ Win + E로 파일 탐색기를 엽니다.
  2. 왼쪽에서 내 PC를 누르고 로컬 디스크 (C:)를 더블클릭합니다.
  3. 빈 곳에서 마우스 오른쪽 클릭 → 새로 만들기 → 폴더.
  4. 이름을 project로 적고 Enter.
탐색기 주소창에 이렇게 보이면 성공 내 PC › 로컬 디스크 (C:) › project
폴더 이름은 영어 소문자, 띄어쓰기 없이 만드세요. 한글이나 띄어쓰기가 들어간 폴더는 명령어에서 오류가 나기 쉽습니다.

3-2PowerShell에서 폴더 이동하기 (cd)

cd는 "change directory", 즉 폴더로 들어가기입니다. 지금 어디에 있는지는 PS 뒤에 보이는 주소로 알 수 있어요. 아래 순서대로 하나씩 따라 해 보세요.

① project 폴더로 바로 가기
cd C:\project
② 한 단계 위(상위 폴더)로 나가기
cd ..
③ 지금 위치 안의 project 폴더로 들어가기
cd project
④ 지금 폴더를 탐색기 창으로 열기
explorer .
PS C:\Users\선생님이름> cd C:\project PS C:\project> cd .. PS C:\> cd project PS C:\project> ← 이 상태에서 에이전트를 부르면 됩니다
꿀팁: cd pro까지만 치고 Tab을 누르면 폴더 이름이 자동으로 완성됩니다.

3-3다음에 배울 것

오늘은 탐색기에서 마우스로 폴더를 만들었지만, 다음 회차부터는 mkdir 폴더이름 한 줄로 PowerShell에서 바로 만드는 법을 배웁니다.

Hello Agent: 첫 지시 3개

15분

에이전트가 켜진 상태(4단계 마지막 화면)에서 아래 문장을 하나씩 복사해 붙여 넣고 Enter를 누르세요. 이제부터는 한국어로 말하면 됩니다.

"허용하시겠습니까?"라고 물어보면

에이전트는 파일을 만들거나 명령을 실행하기 전에 확인을 받습니다. 무엇을 하려는지 한 줄 읽어 보고 괜찮으면 허용(Yes)을 고르세요.

파일 삭제나 C:\project 폴더 바깥을 건드리려 하면 거절(No)하고 다시 설명해 주면 됩니다.

5-1파일 만들기

에이전트에게
이 폴더에 '환영합니다.txt' 파일을 만들고, 안에 오늘 날짜와 "수요 AI 에이전트 빌더스 1회차 출석!"이라고 적어줘.

확인: 열어 둔 C:\project 탐색기 창에 환영합니다.txt가 생겼나요? 더블클릭해서 내용을 열어 보세요.

5-2내 컴퓨터 읽기

에이전트에게
이 폴더에 어떤 파일이 있는지 보여주고, 내 컴퓨터의 Windows 버전과 오늘 요일도 알려줘.

웹 챗봇은 내 컴퓨터를 볼 수 없지만, 에이전트는 직접 확인해서 답합니다.

5-3브라우저 띄우기 오늘의 하이라이트

에이전트에게 · ○○○ 자리에 내 이름
'○○○ 선생님, 환영합니다!'라는 문구가 들어간 환영 카드 웹페이지를 welcome.html로 예쁘게 만들고, 브라우저로 열어줘. 가을 느낌의 색으로 해줘.

브라우저에 내 이름이 들어간 카드가 뜨면 성공입니다. 마음에 안 드는 부분은 그대로 말해 보세요.

더 해보기
글자를 더 크게 하고, 카드에 단풍잎이 천천히 떨어지는 애니메이션을 넣어줘.
에이전트 끝내기: Ctrl + C를 두 번 누르거나 /exit를 입력합니다. 그다음 PowerShell 창을 닫으면 됩니다.

막혔을 때

언제든
'claude'(또는 codex·agy·grok) 용어가 cmdlet, 함수… 이름으로 인식되지 않습니다

설치 직후에 자주 나옵니다. PowerShell 창을 닫고 새로 연 뒤 다시 입력하세요. 그래도 안 되면 노트북을 재시작합니다.

"이 시스템에서 스크립트를 실행할 수 없으므로…" 오류

보안 설정 때문입니다. 아래 명령을 먼저 실행한 뒤 설치 명령을 다시 붙여 넣으세요. 지금 연 창에서만 적용되니 안전합니다.

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
'irm'은(는) 내부 또는 외부 명령… 이 아닙니다

PowerShell이 아니라 CMD를 연 것입니다. 창을 닫고 2-1처럼 PowerShell을 다시 여세요. 꼭 CMD를 써야 한다면 Claude Code는 아래 명령으로 설치할 수 있습니다.

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
설치 명령을 넣었는데 아무 반응이 없어요

설치 프로그램은 진행 표시 없이 내려받는 경우가 많습니다. 1~2분 기다려 보세요. 새 줄에 PS C:\…>가 다시 나타나면 끝난 것입니다.

로그인 브라우저 창이 안 떠요

PowerShell 화면에 https://로 시작하는 주소가 보이면, 그 주소를 마우스로 드래그해 복사한 뒤 크롬 주소창에 붙여 넣으세요. 로그인 후 받은 코드가 있으면 PowerShell에 붙여 넣습니다.

백신(Windows 보안)이 파일을 막았다고 나와요

Windows 11에서 새 프로그램을 처음 실행할 때 잠시 검사하는 경우가 있습니다. 몇 분 기다린 뒤 다시 실행해 보세요. 계속 막히면 강사에게 알려 주세요.

학교 와이파이에서 설치가 안 돼요

학교망이 외부 설치 주소를 막는 경우입니다. 휴대폰 핫스팟에 연결한 뒤 다시 시도하세요.
