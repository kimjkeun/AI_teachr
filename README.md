# 수요 AI 에이전트 빌더스 · 개인 웹 배포 안내

| 파일 | 용도 |
| :--- | :--- |
| `index.html` | 안내 페이지 + 사전 설문 + 결과판 (이 파일 하나만 웹에 올리면 됨) |
| `apps-script.gs` | 구글 스프레드시트에 붙여 넣을 설문 저장 코드 |

```
index.html ──제출(POST)──▶ Apps Script 웹 앱 ──▶ 구글 시트 '응답' 탭
           ◀─결과판(GET)──
```

---

## 1. 구글 시트 + Apps Script 준비 (약 5분)

> ⚠️ **개인 Gmail 계정**으로 진행하세요. 학교·교육청 구글 계정(Workspace)은 "모든 사용자" 공개 배포가 막혀 있는 경우가 많습니다.

1. [sheets.new](https://sheets.new) 에서 새 스프레드시트를 만들고 이름을 `수요 AI 빌더스 설문` 으로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 코드(`function myFunction…`)를 지우고 `apps-script.gs` 내용을 통째로 붙여 넣은 뒤 **저장(💾)** 합니다.
4. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
   - 유형 선택(⚙️) → **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** 클릭
5. 권한 승인 창이 뜨면 내 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**.
   (내가 만든 스크립트라 뜨는 일반적인 경고입니다.)
6. 표시되는 **웹 앱 URL** (`https://script.google.com/macros/s/……/exec`) 을 복사합니다.
7. 확인: 그 URL을 브라우저 주소창에 붙여 넣었을 때 `{"ok":true,"rows":[]}` 가 보이면 성공입니다.
   이때 시트에 `응답` 탭이 자동으로 생깁니다.

## 3. 웹에 올리기

`index.html` 은 파일 하나로 동작하는 정적 페이지라 어디에 올려도 됩니다.

- **Vercel**: 이 폴더를 GitHub 저장소에 올리고 Vercel에서 Import → Deploy.
- **GitHub Pages**: 저장소 Settings → Pages → 브랜치 선택.
- **기존 개인 웹/서버**: `index.html` 을 원하는 경로에 업로드.

올린 뒤 페이지에서 직접 한 번 제출해 보고, 시트에 한 줄이 생기는지 확인하세요.

## 운영 메모

- **응답 보기·정리**: 시트 `응답` 탭에서 바로 보고, 정렬하고, 행을 지우면 결과판에서도 사라집니다.
  A·B열(이름 키, 비밀번호)은 숨겨 두었습니다. A열은 지우지 마세요.
- **본인 응답 수정**: 설문에서 이름 + 숫자 4자리 비밀번호를 정해 제출합니다.
  나중에 어느 기기에서든 "이미 제출하셨나요?" 칸에 이름과 비밀번호를 넣으면 불러와 고칠 수 있습니다.
  같은 이름 + 같은 비밀번호로 다시 제출해도 원래 줄이 수정됩니다. (띄어쓰기·대소문자 차이는 같은 이름으로 봅니다.)
- **비밀번호를 잊은 선생님**: 시트에서 숨긴 열을 펼친 뒤(A열 왼쪽 ◀▶ 클릭) 그 줄의 **B열 칸만 비우세요**.
  그 선생님이 다음에 아무 4자리로 불러오거나 제출하면 그 번호가 새 비밀번호가 됩니다.
- **비밀번호를 5번 틀리면** 그 이름은 10분간 잠깁니다. 비밀번호는 해시로만 저장되어 운영자도 원래 숫자를 볼 수 없습니다.
- **이름이 같은 선생님이 두 분이면** 나중에 제출하는 분이 "비밀번호가 맞지 않아요" 안내를 받습니다. 이름 뒤에 과목 등을 붙여 구분하도록 안내되어 있습니다.
- **결과판 갱신**: 제출 직후, 그리고 페이지를 열어 둔 동안 30초마다 새로 불러옵니다.
- **공개 범위**: 페이지 주소를 아는 사람은 누구나 결과판(이름, 응답)을 볼 수 있습니다.
- **Apps Script 코드를 고쳤다면**: **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포**.
  이렇게 하면 URL이 그대로 유지됩니다. ("새 배포"를 다시 누르면 URL이 바뀝니다.)
